# Contributing

Gracias por tu interés en este proyecto.

FleetLogix fue desarrollado como parte del Proyecto Integrador del Módulo 2 del Bootcamp de Data Science de SoyHenry.

Actualmente este repositorio tiene fines educativos y de portafolio, por lo que no se aceptan contribuciones externas.

Si deseas utilizar este proyecto como referencia para aprender Ingeniería de Datos, eres libre de explorar el código, siempre respetando los términos de la licencia MIT.

---

## Tecnologías utilizadas

- Python
- PostgreSQL
- SQL
- Snowflake
- Amazon Web Services (AWS)
